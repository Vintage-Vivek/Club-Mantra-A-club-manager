About Club Mantra

Club Mantra is a college club management app designed to help students manage their clubs efficiently. This project was created by Vivek to simplify the process of creating, editing, and managing club details.

How the Website Works

This website allows users to create club cards for their college clubs. Users can add a club using the "Register Club" button, edit club details using the "Edit" button, and delete clubs using the "Delete" button.
